Privacy Policy

Last Updated: September 6, 2026

1. Introduction

nekzuk Software ("we", "us", or "our") respects your privacy and is committed to protecting your personal information. This Privacy Policy explains how we handle information on our website (https://nekzuk.com) and within our software products.

2. Website Information Collection

2.1 Google Analytics

Our website uses Google Analytics to improve the site and enhance user experience.

  • Information Collected: Page views, visitor count, time on site, referral sources, device information, and clicks on links to product details, trial downloads, and purchase destinations
  • IP Address Anonymization: IP addresses are anonymized and cannot be used to identify individuals
  • Cookie Usage: Google Analytics uses cookies to collect access information
  • Opt-Out: You can disable data collection using the Google Analytics Opt-out Browser Add-on

For more details, please see Google's Privacy Policy.

3. Software Information Handling

3.1 Local-First Processing and Storage

Our software products primarily process and store data on your PC. Internet communication is used for features that use external API services, update checks and downloads, and data or model downloads required by some features.

  • Local-First Processing and Storage: Settings, histories, and generated or processed data are generally stored on your PC
  • No Collection by Us: Nekzuk does not collect or store user information, usage data, prompts, input or reference images, generated images, or other processed data
  • Required Communication: An internet connection is used for features that use external API services, update checks and downloads, and data or model downloads required by some features
  • No License Activation: No online authentication or personal information registration is required

3.2 Use of External API Services

Features that use external API services, such as those provided by NovelAI, OpenAI, and Google, send the prompts, input or reference images, and other data needed for processing directly to the relevant service. Please refer to each service's terms and privacy policy for how it handles submitted data.

  • API Key Storage: API keys obtained by users are stored only on your PC
  • No Collection by Us: Nekzuk does not collect or store API keys, prompts, input or reference images, generated images, or API communication content
  • Communication Logs (NovelAI Features): Local communication log storage can be enabled/disabled by user choice. When saved, logs are stored only on your PC
