01 Features

Keep the generation info that conversion usually loses.

Change formats and reduce file size while preserving the AI generation info that ordinary image conversion often strips away.

Convert with generation info

Converted images still load in WebUI.

  • Metadata-preserving conversionPNG / WebP / JPEG → PNG / WebP / JPEG, including output in the same format as the input
  • WebUI importConverted images can be loaded into WebUI’s PNG Info

Make files lighter

Save storage and make sharing easier.

  • Strong compressionPNG → JPEG cuts file size to as little as about 1/10
  • Quality & size adjustmentAdjust conversion quality and scale images down
  • File size optimizationSave smaller files; PNG reduces the number of colors
  • Lossless compressionSave with priority on quality (larger files)

Process in bulk

Convert whole folders of images at once.

  • Batch conversionSelect a folder or drag & drop to convert many images at once
  • Output & original filesOptionally save next to the input files or delete the originals after conversion
  • Eagle supportConverts Eagle libraries
  • Command line (CLI)Also runs from the command line
