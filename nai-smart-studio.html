01 Features

Beyond the official web UI.

Keep NovelAI's image generation features, and add tools for writing prompts, automating generation, and organizing the results.

Find and build prompts

Quickly find useful prompts and frequently used tags.

  • Prompt searchSearch a built-in database for prompts to use as references
  • Tag completion & presetsAutocomplete tags and load presets
  • WildcardsGenerate prompt variations

Automate generation

Hand off the generation you used to repeat by hand.

  • Batch generationGenerate multiple batches automatically
  • Story generationCreate a story and matching illustrations from characters and a synopsis
  • Command line (CLI)Run image generation from the command line

Organize and finish

Keep working with your images in the same app.

  • HistoryQuickly pull up images from your generation history
  • TaggerGenerate tags that reproduce an existing image
  • Proprietary upscalingUpscale without spending Anlas, often with better results than the official upscaler. *Opus plan only
  • Eagle integrationSend generated images to Eagle

All the NovelAI
features you know

  • Access to almost all basic image generation features
  • Supports NovelAI Diffusion V5 (Full / Curated)
  • Text-to-Image, Image-to-Image, and Inpainting
  • NovelAI Potion and Precise Reference
  • Director Tools (clutter/background removal, line art/sketch, colorization, expression changes)
  • Prompt chunks
Your data
Settings, history, and generated images are stored on your PCOnly the prompts and input or reference images needed for generation are sent to the NovelAI API. nekzuk Software does not collect or store them.
