01 処理例

動きに合わせて、処理を続ける。

人物の顔と車のナンバープレートを処理したサンプルです。移動する対象への追従を、動画で確認できます。

02 できること

自動で処理して、必要なところを調整。

動画・アニメーションの検出から仕上げまでを、ひとつのアプリで。

AIで自動検出・追跡

対象の動きに合わせて処理範囲を追跡。複数の動画にも同じ設定をまとめて適用できます。

微調整・手動編集

自動処理の結果を確認して、範囲を微調整。手動で範囲を指定し、選択した範囲を動きに合わせて追従させることもできます。

後編集用の素材も出力

処理部分のみの動画や白黒マスク動画を出力し、ほかの動画編集ソフトでの仕上げに使えます。

03 画面と使い方

追加して、設定して、仕上がりを確認。

動画やアニメーションを追加し、検出対象・加工方法・出力設定を選びます。

  1. 1

    入力ファイルを追加する

    動画やアニメーションを、ファイル・フォルダ単位で追加。

  2. 2

    処理と出力を設定する

    検出設定・処理モード・出力設定を選択。処理する時間範囲を絞ることで、処理時間を短縮できます。

  3. 3

    処理を開始する

    処理中に表示される警告も確認。

  4. 4

    出力全体を確認する

    必要に応じて、処理範囲を微調整。

微調整・手動編集は、動画とアニメーションの両方に対応しています。

04 対応形式

動画にも、アニメーションにも。

01 入力できる形式

MP4 / MOV / AVI / MKV / WebM / M4V / WMV / TS / MTS / M2TS

アニメーションGIF / アニメーションWebP

02 出力できる形式

  • MP4 / MKV（H.264 / H.265）
  • アニメーションGIF / アニメーションWebP（入力と同じ形式で出力）
  • 先頭音声ストリームの保持に対応

映像設定品質・映像ビットレート・目標容量から設定できます。

出力時の注意追加の音声や字幕などは保持されません。動画によっては、動きや色合いが元動画と異なる場合があります。

05 動作環境

お使いのPCをご確認ください。

CPUのみでも動作しますが、処理時間は大幅に長くなる場合があります。NVIDIA GPUの使用を推奨します。

処理時間は、動画の解像度・長さ・処理設定・PC/GPU性能により変わります。
